# API reference

Generated by `tools/gen_api.py` from the package sources - do not edit by hand. Every function is pure unless noted; units are SI (metres, kilograms, seconds, joules, kelvin) unless a name says otherwise.

Import with `import "<package>" as x` (put `packages/` on `LARZSCRIPT_PATH`). Private helpers start with `_`.

## `physmath`

Maths core: trigonometry, exp/ln, inverse hyperbolics, a correct sqrt, number formatting.

```text
physmath - the maths Larzscript does not ship, in pure Larzscript.

Larzscript has sqrt and whole-number pow, but no sin/cos/tan, exp/ln,
inverse trig or fractional powers - and str() only prints 6 significant
digits, which is useless for physics. This package fills that gap with
routines accurate to ~1e-15 relative (checked against IEEE double
references in tests/test_physmath.lz), so the quantum / relativity /
astro packages built on it can be trusted to the last digit that matters.

  import "physmath" as m
  print(m.sin(m.PI / 6))          # 0.5
  print(m.sci(m.exp(-50), 4))     # 1.929e-22

Accuracy notes (all measured, see the tests):
  sin/cos/tan   ~1e-16 relative for |x| up to ~1e6 rad (three-part
                Cody-Waite reduction); still sensible beyond, but the
                reduction loses about one digit per factor of 10.
  exp/ln        ~1e-16 relative over the whole double range.
  atan/asin/... ~1e-16.
```

**Constants:** `PI`, `TAU`, `HALF_PI`, `E`, `LN2`, `LN10`, `SQRT2`

## `physconst`

Physical and astronomical constants (SI 2019, CODATA 2018, IAU 2015).

```text
physconst - physical and astronomical constants, GENERATED by tools/gen_constants.py (do not edit).

Larzscript has no exponent syntax, so each value below is a plain decimal literal; the
scientific-notation value, unit and source are in the trailing comment. Kinds:
  exact     SI 2019 defining constants - exact by definition
  derived   exact consequences of those (or of IAU definitions)
  measured  CODATA 2018 recommended values (NIST) - carry a standard uncertainty
  nominal   IAU 2015 nominal values - conversion constants, not measurements

  import "physconst" as k
  print(k.c)      # 299792458
```

**Constants:** 7 values; `INFO` maps each name to its unit, kind (exact / derived / measured / nominal), source and note. See the table in the source.

## `quantum`

Quantum-circuit simulator: states, gates, measurement, circuits, entanglement.

```text
quantum - a real quantum-circuit simulator in pure Larzscript.

A state is a dict {"n": qubits, "re": [...], "im": [...]} holding the 2^n complex
amplitudes as two parallel lists (fast: gates touch only the amplitude pairs they
change). Gates mutate the state in place and return it, so calls chain naturally.

  import "quantum" as q
  let s = q.zero(2)                 # |00>
  q.h(s, 0); q.cnot(s, 0, 1)        # Bell state (|00> + |11>) / sqrt 2
  print(q.state_str(s, 4))          # 0.7071|00> + 0.7071|11>
  print(q.sample(s, 1000))          # {"00": ~500, "11": ~500}

CONVENTION: qubit 0 is the LEFTMOST bit, as in textbooks - |q0 q1 q2>. Basis index i
has qubit k at bit (n-1-k) of i, so "011" is index 3 with q0=0, q1=1, q2=1.
Measurement is seedable: q.seed(42) makes every run reproducible.

Practical size: ~30 ms per gate at 12 qubits, ~120 ms at 14 (native interpreter).
Cross-checked against an independent brute-force implementation in
tools/gen_ref_quantum.py (full Kronecker-product matrices) - see tests/.
```

**Constants:** `INV_SQRT2`, `MAX_QUBITS`

## `qalgo`

Quantum algorithms: QFT, Grover, Deutsch-Jozsa, Bernstein-Vazirani, teleportation, phase estimation, CHSH, Shor.

```text
qalgo - famous quantum algorithms, run on the `quantum` simulator.

Every routine here builds a real circuit (Hadamards, controlled phases, CNOTs) and runs
it on the statevector; the results are compared with the textbook formulas in
tests/test_qalgo.lz. NOTE: Larzscript's `for i from a to b` counts DOWN when b < a, so
this file uses range() for every loop that can be empty.

  import "qalgo" as qa
  print(qa.shor(15, 7))           # {"period": 4, "factors": [3, 5], ...}
  print(qa.grover(4, [11])["p_marked"])     # 0.9613...  (3 iterations of 16 items)
```

## `qmech`

Textbook quantum mechanics: hydrogen, photons, de Broglie waves, box, oscillator, tunneling.

```text

  import "qmech" as qm

Formulas (all from first principles + CODATA 2018 constants in physconst):
  Bohr model / Rydberg      E_n = -h c R_inf / n^2                       (infinite nuclear mass)
  photon                    E = h c / lambda,   p = h / lambda
  de Broglie                lambda = h / p
  Heisenberg                sigma_x sigma_p >= hbar / 2
  particle in a box         E_n = n^2 h^2 / (8 m L^2)
  harmonic oscillator       E_n = hbar omega (n + 1/2)
  tunneling (rect. barrier) T = 1 / (1 + V0^2 sinh^2(kappa a) / (4 E (V0 - E)))     for E < V0
Each is validated against textbook reference values in tests/test_qmech.lz.
```

## `relativity`

Special and general relativity, black holes, GPS.

```text
relativity - special and general relativity calculators, in SI units.

  import "relativity" as rel
  import "physconst" as k
  print(rel.gamma(0.99 * k.c))                         # 7.0888
  print(rel.schwarzschild_radius(k.M_sun))             # 2953.25 m
  print(rel.gps_clock_offset_us_per_day())             # +38.45 microseconds per day

Special relativity: gamma, time dilation, length contraction, velocity addition, Doppler,
E = gamma m c^2, rapidity, and the constant-acceleration "relativistic rocket".
General relativity (Schwarzschild vacuum): event horizon, gravitational time dilation and
redshift, photon sphere, ISCO, Hawking temperature and lifetime, Bekenstein-Hawking
entropy, and the GPS clock correction. Validated in tests/test_relativity.lz against
independent calculations and published values (GPS +38 us/day, Pound-Rebka 2.46e-15,
Sun r_s = 2.95 km, Earth r_s = 8.87 mm, Hawking T(Sun) = 6.17e-8 K).

Numerical care: 1 - beta^2 is computed as (1 - beta)(1 + beta), so gamma stays accurate as
beta -> 1; kinetic energy uses (gamma - 1) = beta^2 gamma^2 / (gamma + 1) to avoid
cancellation at low speed.
```

## `astro`

Stars, planets, distances and flat-LCDM cosmology.

```text
astro - stars, planets, distances and cosmology, in SI units (helpers for light-years,
parsecs, AU and Gyr included).

  import "astro" as a
  import "physconst" as k
  print(a.light_travel_time_s(k.AU) / 60)           # 8.32 minutes: sunlight to Earth
  print(a.star_luminosity_w(k.R_sun, k.T_sun))      # 3.83e26 W (the Sun, from R and T alone)
  print(a.hubble_age_gyr(67.4, 0.315))              # 13.8 Gyr (Planck 2018 flat LCDM)
```
